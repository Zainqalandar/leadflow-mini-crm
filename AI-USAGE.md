# AI Usage

AI developer tools were used as part of the normal development workflow for this assessment. They supported my work; they were not treated as a replacement for understanding, review, or testing.

## Areas where AI assisted

- Exploring the monorepo structure and breaking the assessment into deliverable milestones.
- Reviewing API route design, validation, authentication, and error-handling choices.
- Helping troubleshoot Docker, MongoDB, CORS, build, and deployment configuration issues.
- Suggesting UI layout ideas and CSS refinements for the React and Angular views.
- Reviewing WordPress plugin security concerns such as nonces, sanitization, escaping, and server-to-server requests.
- Improving setup documentation, Postman notes, and verification checklists.

## Ownership and verification

I selected the architecture, connected the applications, configured the environments, reviewed the generated suggestions, and made the final implementation decisions. The code was checked with TypeScript/build commands, API smoke tests, and manual end-to-end testing across WordPress, the API, MongoDB, React, and Angular.

No real client data was used. Secrets remain in local environment files and are excluded from Git.
